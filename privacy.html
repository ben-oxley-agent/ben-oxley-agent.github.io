Privacy policy

Family Wall · last updated 18 November 2026

Family Wall is a self-hosted application that runs on hardware owned by the person who installs it. This policy explains what data the application handles, where it goes, and how it can be removed. It applies to family-wall and to the Google account authorisation used by it.

Who is responsible

Family Wall is not a service and has no operator. It is software installed by an individual on their own device, and the person who installs it is the only party that holds the data it processes. There is no server belonging to the author of the software, and no data is transmitted to the author.

What is collected

DataSourceWhy
Calendar events — titles, times, locations, descriptions, recurrence Google Calendar, for the calendars the owner selects To draw the week view and to write back events created on the device
Task lists — titles, due dates, completion state Google Tasks, for the account the owner authorises To show shopping and to-do items, and to tick them off
Chores, routines, star balances and rewards Entered on the device The household's own chore chart
Meal plan entries and shopping list items Entered on the device, or a self-hosted recipe manager on the same network To show the week's meals and shopping
Operational logs Generated by the application itself To diagnose failures. Contains request paths, timings and client IP addresses on the local network. Retained 14 days, then deleted.

Family Wall does not access Gmail, Google Drive, Google Contacts, Google Photos, or any Google service other than Calendar and Tasks. It does not request the user's name, email address or profile.

Where the data is stored

Everything is stored on the device running the application — a single SQLite database file on the local disk, plus a token file holding the Google authorisation. The token file is created with owner-only file permissions. No copy is kept anywhere else.

What is shared, and with whom

Nothing is shared with any third party. Specifically:

  • No analytics, tracking, advertising or crash-reporting service is used.
  • No data is sent to the author of the software, or to any server other than Google's own APIs.
  • The only outbound network requests are to Google Calendar and Google Tasks, to the local network's recipe manager if one is configured, and to a public weather API for the forecast, which receives no personal data and no identifiers.
  • The device is not exposed to the internet. It is reachable only from the household's own local network.

Google user data and the Limited Use requirements

Family Wall's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. In practice:

  • Google Calendar and Google Tasks data is used only to provide the calendar, task and shopping features described above.
  • It is not transferred to third parties, not used for advertising, and not used to train machine learning models.
  • It is not used for any purpose the owner has not asked for.
  • No humans read the data, because no third party has access to it.

How long it is kept, and how it is deleted

Calendar and task data is kept only for as long as it is needed to draw the screens, which is a rolling window around the current week; entries outside that window are deleted automatically during sync. Operational logs are deleted after 14 days. All remaining data can be removed at any time by deleting the database file on the device, or by uninstalling the application.

Revoking Google access

The owner can revoke Family Wall's access to their Google account at any time at myaccount.google.com/permissions. Revoking access immediately invalidates the stored token; the application then stops syncing and continues to work with locally entered data only. Deleting the token file on the device has the same effect.

Children's data

The device is used by a household that includes a child, and stores the child's first name, chores, star balance and any calendar entries created for them. This data is entered and controlled by the parent, stays on the parent's own device, is not shared, and is not used for advertising, profiling or any automated decision-making. It is not visible to the author of the software.

Changes

If this policy changes, the date at the top of this page will change with it. Since the software is installed rather than delivered as a service, changes only take effect on a device when its owner updates it.
